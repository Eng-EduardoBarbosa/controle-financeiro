# Controle Financeiro

Aplicação desenvolvida em Java para controle de lançamentos financeiros, permitindo registrar e visualizar informações de receitas e despesas.

## 📌 Sobre o projeto

Este projeto foi desenvolvido como prática de programação em Java, aplicando conceitos de Programação Orientada a Objetos e manipulação de dados.

A aplicação funciona em modo console e permite trabalhar com lançamentos financeiros de forma simples.

## 🚀 Funcionalidades

- Cadastrar lançamentos financeiros
- Visualizar lançamentos
- Trabalhar com valores financeiros
- Identificar receitas e despesas
- Interagir com o sistema pelo terminal

## 🛠️ Tecnologias utilizadas

- Java
- Programação Orientada a Objetos
- Git
- GitHub

## 📚 Conceitos praticados

- Classes e objetos
- Atributos
- Encapsulamento
- Construtores
- Métodos
- ArrayList
- Estruturas condicionais
- Estruturas de repetição
- Entrada de dados com Scanner

## ▶️ Como executar

1. Clone o repositório.
2. Abra o projeto em uma IDE compatível com Java.
3. Execute o arquivo `App.java`.
4. Utilize o menu apresentado no terminal.
